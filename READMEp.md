MOVIE TICKET BOOKING SYSTEM

Project Description:
This project is a simple Movie Ticket Booking System. It collects customer, movie, show, seat, and ticket price details and displays the complete booking information.

Features:

1. Customer Details
   
   - Customer Name
   - Mobile Number
   - Email

2. Movie Details
   
   - Movie Name
   - Language
   - Genre
   - Duration

3. Show Details
   
   - Theatre Name
   - Show Date
   - Show Time

4. Seat Selection
   
   - Display available seats
   - Select available seats
   - Display selected seats

5. Ticket Price
   
   - Enter ticket price
   - Count selected seats
   - Calculate total amount

Formula:
Total Amount = Number of Selected Seats × Ticket Price

Output:
After completing the booking, the system displays:

- Customer details
- Movie details
- Show details
- Selected seats
- Ticket price
- Total amount

Algorithm:

1. Start
2. Enter customer details.
3. Enter movie details.
4. Enter show details.
5. Display available seats.
6. Select available seats.
7. Display selected seats.
8. Enter ticket price.
9. Calculate total amount.
10. Display complete booking details and total amount.
11. Stop.
